How to process a collection day (no need to update orders one by one)
  1. Cut-off: pick the collection day, tick the box at the top of the table to select all, then Mark processing. Staff can no longer cancel those orders.
  2. Prepare: open the Pick list. It has the total of each item to pull from storage and a packing list per person. Print it and pack.
  3. Ready: select all again and click Mark ready.
  4. Collection day: search for each person as they arrive and click ✓ Collected.
